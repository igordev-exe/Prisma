# Prisma

Bem-vindo ao Prisma! Este é um site estático para apresentação de cursos e serviços educacionais.

## 📋 Descrição

Prisma é uma plataforma educacional que oferece diversos cursos para você desenvolver suas habilidades.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização responsiva
- **JavaScript** - Interatividade

## 📁 Estrutura do Projeto

```
Prisma/
├── index.html          # Página inicial
├── css/
│   └── style.css       # Estilos globais
├── js/
│   └── script.js       # Scripts JavaScript
└── README.md           # Este arquivo
```

## 🎯 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/igordev-exe/Prisma.git
cd Prisma
```

2. Abra o arquivo `index.html` em seu navegador

3. Para fazer alterações, edite os arquivos HTML, CSS e JavaScript conforme necessário
